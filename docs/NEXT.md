## Решено, делаем после анализа статистики
- План хранения под 10 ГБ (см. `research/bohemia-api-observations.md`, раздел «План хранения»).
- Оптимизация опроса: `listPlayers` по сохранённому roomId, `rooms/search` раз в N минут и при `ROOM_NOT_FOUND`.
- Исключать запароленные комнаты из выборки (после того, как узнаем поле фильтра).

## Следующая функциональность
- REST API для телеграм-бота (отдельный проект): `GET /events?after=<id>&player_ids=…` (курсор у бота, `startup_replay` исключён),
  `GET /players?nick=…`, `GET /players/{id}`, `GET /players/{id}/sessions`, `GET /servers?tracked=true`; `Authorization: Bearer API_TOKEN`.
  Подписки, чаты и тексты сообщений — на стороне бота.
