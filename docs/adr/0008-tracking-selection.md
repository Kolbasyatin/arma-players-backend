# ADR 0008 — Выбор серверов для минутного опроса (tracking_enabled)

**Статус:** Accepted · **Дата:** 2026-09-10

## Контекст

В лобби ~5050 серверов, из них ~4050 пустых, ~200 с онлайном от 10 игроков (скан 2026-09-10). Опрашивать все раз в минуту — 10 000 запросов в минуту к Bohemia, неприемлемо. AGENTS.md предполагает ручной выбор администратором; пользователь хочет автоматику по онлайну, чтобы не выбирать руками из сотен.

## Решение

Флаг `server.tracking_enabled` пересчитывается после каждого успешного полного скана по двум правилам, источник фиксируется в `server.tracking_source`:

1. **MANUAL** — адреса из конфигурации `TRACK_HOST_ADDRESSES` (список `ip:port`). Всегда включены, пока есть в списке; исчезли из списка — выключаются.
2. **AUTO** — если `TRACK_AUTO_MIN_PLAYERS > 0`: активные серверы, у которых **пиковый** `player_count` по всем снимкам за окно `TRACK_AUTO_LOOKBACK` (по умолчанию 7 дней) не ниже `min`, отсортированные по пику, не более `TRACK_AUTO_MAX_SERVERS`. Серверы, выпавшие из этого набора, выключаются; ручные не трогаются.

   Почему пик за окно, а не последний снимок: суточный скан может попасть на рестарт сервера (0 игроков), и по одному снимку сервер с 128 онлайна выпал бы из опроса на сутки. Пик за неделю устойчив к рестартам и ночным провалам; сервер, который реально опустел, выпадает через неделю.

Конфигурация — источник истины: флаг в БД не редактируется руками, иначе следующий скан его перезапишет. Когда появится web-интерфейс, ручной список переедет из env в таблицу с тем же смыслом.

Пересчёт раз в сутки означает: новый сервер, набравший онлайн днём, попадёт в AUTO только после следующего скана. Уже отслеживаемый сервер из выборки при этом не выпадает благодаря пику за окно. При необходимости добавим лёгкий пересчёт чаще.

## Последствия

- Число опрашиваемых серверов ограничено сверху `len(MANUAL) + MAX`, нагрузка на Bohemia предсказуема: 2 запроса в минуту на сервер.
- История tracking_source позволяет понять, почему сервер попал в выборку.
- Смена состава AUTO приводит к закрытию сессий по data gap на выпавших серверах — это ожидаемо и помечено.
